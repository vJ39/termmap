ネイティブ端末(iTerm2/Terminal.app 等)でのマウス操作に対応する設計。web版のタッチ/マウス操作は
`web/touch-overlay.js` → PAN マーカーの経路で既に動いており、今回はそれとは別に crossterm の
`Event::Mouse` を受ける。

## 1. 操作

| 操作 | 条件 | 動作 |
|---|---|---|
| 左ドラッグ | 押下位置が地図領域内 | 地図がカーソルに1:1で追従してパン。軸ごとに `dragmode::axes(focus)` が `Pan` の軸だけ動く(PoiList は横のみ) |
| 左クリック(押して離す間に動かない) | Focus::Map・地図領域内 | クリックした地点を地図の中心にする |
| ホイール上/下 | Focus::Map・地図領域内 | ズームイン/アウト。カーソル下の地点が同じ画面位置に留まるよう中心を補正する(z 2〜19) |
| 左クリック | 閉じられるパネル(オンボーディング/QR/名前ポップアップ/災害事例/規制詳細)表示中 | パネルを閉じる(キー入力と同じ扱い) |
| 上記以外 | y/n 確認中など | 無視 |

左袖(一覧)・ステータス行・標高帯でのクリックは今回対象外(無視)。

## 2. 座標の換算

地図領域は列 `gut .. gut+map_cols`・行 `0 .. map_rows`。地図中心は領域の中央
(`gut + map_cols/2`, `map_rows/2`)。1セルあたりの世界ピクセル(zoom z)は
横 `ow/map_cols`・縦 `oh/map_rows`(実画像モードでは `rw/scale`・`rh/scale` を使う。PAN マーカーと同じ
`dragmode::Layout` を流用する)。

- ドラッグ: 前回位置からのセル差 (dc, dr) を比 `fx=dc/cols, fy=dr/rows` にして `dragmode::apply_pan`
  へ渡す。PAN マーカーと同じ換算・同じ正規化(X は巻き、Y はクランプ)になる。
- クリック: セル中心 (col+0.5, row+0.5) と地図中心の差 × 1セルあたりピクセル を中心へ足す。
- ホイール: カーソルの中心からのオフセットを d[px] とすると、ズームイン後の中心は `2cx + d`、
  ズームアウト後は `(cx + d)/2 - d`。

## 3. 構成

- 新規 `src/mouse.rs`: 状態 `MouseTracker`(押下位置・前回位置・ドラッグ済みフラグ)と、
  `MouseEvent` → `MouseAction`(Pan / Click / Zoom / None)の純関数、座標換算の純関数。
  端末や UiState に依存しないのでユニットテストで網羅できる。
- `src/ui.rs`: `Event::Mouse` を受けたら `MouseTracker` に通し、結果を UiState へ適用。連続する Drag
  イベントは PAN マーカーと同じく溜まった分を合算して1フレームで適用する(描画待ちで取りこぼさない)。
- `src/ui_helpers.rs` `TermGuard`: マウス報告の有効化と、終了時の解除。設定 `[display] mouse`
  (既定 true)が false なら有効化しない(端末のテキスト選択を使いたい人向け)。
- web版: ブラウザのタッチ/マウスは `web/touch-overlay.js` が PAN マーカーで送っているので、
  `scripts/serve-web.sh` が環境変数 `TERMMAP_NO_MOUSE=1` を渡し、termmap 側はマウス報告を有効にしない
  (有効のままだと xterm.js のマウス報告と二重にパンする)。
- 有効にするモードは押下/ドラッグ(`?1000`/`?1002`)と SGR 形式(`?1006`)だけ。crossterm の
  `EnableMouseCapture` は全移動報告(`?1003`)まで入り、ボタンを押していないカーソル移動でも
  イベントが届き続けるので使わない。

## 4. テスト方針

- mouse.rs: 地図領域の内外判定、クリックとドラッグの判別(動かなければクリック)、ドラッグ開始が
  領域外なら無視、Drag の差分がパン比になること、クリックの中心移動量、ホイールでカーソル下の
  地点が保たれること(ズームイン/アウト両方・z 上下限)、左袖幅ありの原点ずれ。
- config: `mouse` キーの読み書き(既定 true)。
- 実機: PTY でマウス報告シーケンスを流し、中心座標が動くことを確認する。
